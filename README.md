# HelpMyPresentation

HelpMyPresentation 是一款面向演讲、汇报和公开表达场景的智能提词工具。

## Features

- 实时语音识别与逐词跟随
- 中文和英文稿件支持
- 智能自动滚动与快速朗读定位
- 重点标记和词语批注
- 可保存的便利贴
- 演讲倒计时
- 画中画提词模式
- 可折叠的便利贴和控制台
- 桌面与窄屏设备自适应布局
- 麦克风权限状态管理，减少重复授权提示

## 项目简介

HelpMyPresentation 帮助演讲者减少低头看稿的频率，在保持内容准确的同时，让表达更加自然流畅。

项目重点优化了语音识别定位、快速朗读追踪、自动滚动、麦克风权限管理和响应式布局。便利贴与控制台支持独立折叠，折叠后正文区域会自动扩展，让演讲稿拥有更多可视空间。

## English

HelpMyPresentation is an intelligent teleprompter designed for speeches, presentations, and public speaking.

It provides real-time speech recognition, word-by-word tracking, automatic scrolling, Chinese and English script support, highlights, annotations, sticky notes, timers, and picture-in-picture mode.

The project focuses on fast-reading tracking, speech alignment, scrolling accuracy, microphone permission handling, and responsive layouts. The sticky notes panel and control console can be collapsed independently, allowing the script area to automatically expand on desktop and smaller screens.
