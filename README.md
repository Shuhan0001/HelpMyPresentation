HelpMyPresentation is an intelligent teleprompter designed for speeches, presentations, and public speaking. It supports real-time speech recognition, word-by-word tracking, automatic scrolling, Chinese and English scripts, highlights, sticky notes, timers, and picture-in-picture mode.
The project focuses on improving fast-reading tracking, speech alignment, scrolling accuracy, microphone permission handling, and responsive layouts. Both the sticky notes panel and the control console can be collapsed independently, allowing the script area to automatically expand on desktop and smaller screens
